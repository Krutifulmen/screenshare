# screenshare
A free python open-source screenshare program.
***
# Before start:
* Open folder with source code with **Command Prompt** or **Terminal**
* Run:
> pip install -r requirements.txt
***
# Documentation: 
### For the server:
1. Start file "server.exe"
2. Server will start on ip 0.0.0.0 with port 5000
   
### For the client:
1. Start file "client.exe"
2. Enter IP of server (without port)
3. Wait for connection
* Press Esc for exit
***
# How to build:
* Download source code
#### For Windows:
* Use: **auto-py-to-exe**
